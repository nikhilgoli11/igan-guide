# igAN Guide — publication prototype

This folder contains the static multi-page prototype.

Pages:
- index.html — Home
- journey.html — IgAN journey
- reports.html — report explainer
- track.html — local browser tracker
- treatment.html — treatment overview
- mestc.html — MEST-C explanation
- faq.html — FAQ
- sources.html — sources and methodology

Important:
- This is a static prototype; it is not yet deployed.
- The tracker stores entries in the visitor's browser localStorage.
- Do not add server-side storage of health information without a proper privacy/security design.
- Medical content should be reviewed before public launch.
